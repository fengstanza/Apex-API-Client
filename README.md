## Overview

**Apex API Client** is a fast, clean, and intuitive desktop tool designed to test, debug, and manage RESTful APIs. Built with universal backward-compatibility, it runs seamlessly on legacy systems (Windows 7 SP1) as well as modern operating systems (Windows 10 and Windows 11).

---

## Key Features

* **Universal Windows Support:** Runs smoothly on all 32-bit (x86) and 64-bit (x64) Windows editions without missing DLL errors.
* **Multi-Tab Workspace:** Test multiple API endpoints simultaneously with dedicated Params, Headers, Auth, and Body tabs.
* **Collection Tree:** Sidebar folder tree with drag-and-drop organization to keep requests structured.
* **cURL Interoperability:** One-click cURL Import and Export for instant reproducibility.
* **Authentication Builders:** Native support for Bearer Tokens and Basic Auth.
* **Real-time Diagnostics:** Visual badges for HTTP status codes, latency in milliseconds (ms), and payload sizes in kilobytes (KB).
* **Modern Themes:** Integrated Light and Dark themes.
* **Backup & Restore:** Full data export and import capability via JSON files.

## Download & Installation

1. Go to the [Latest Releases](https://github.com/mrrakib5007/Apex-API-Client/releases/latest) section.
2. Download the installer setup file: `apex_api_client_setup_v1.0_x86.exe`.
3. Run the installer. All required Visual C++ runtime components will be configured automatically.
4. Launch **Apex API Client** directly from your Desktop shortcut or Start Menu.
